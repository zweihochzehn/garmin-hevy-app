# Architecture Decision Records

Short records of the significant decisions behind the **Workouts for Hevy** Garmin
Connect IQ app. Format: [Michael Nygard's ADR template](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions).

| # | Title | Status |
|---|-------|--------|
| [0001](0001-native-connectiq-app.md) | Native Connect IQ (Monkey C) app for Venu 2 | Accepted |
| [0002](0002-data-destinations.md) | Split data destinations: sets → Hevy, HR/calories → Garmin Connect | Accepted |
| [0003](0003-inputdelegate-for-touch.md) | Use `InputDelegate` (not `BehaviorDelegate`) for touch workout screens | Accepted |
| [0004](0004-custom-ui-and-custommenu.md) | Custom-drawn workout screens + `CustomMenu` dark lists | Accepted |
| [0005](0005-api-key-entry.md) | API-key entry: phone settings + on-watch chunked entry | Accepted |
| [0006](0006-end-recording-on-exit.md) | End the activity recording on every workout exit | Accepted |
| [0007](0007-demo-fallback.md) | Bundled demo routine as offline fallback | Accepted |
| [0008](0008-third-party-branding.md) | Third-party branding: "Workouts for Hevy", own icon, disclaimer | Accepted |
| [0009](0009-offline-safety-and-data-fidelity.md) | Offline safety net and faithful set data | Accepted |
